# Vegetable Image Classifier (CNN)

An end-to-end multiclass vegetable image classifier built with TensorFlow/Keras and deployed with Streamlit.

## Project files
- `vegetable_cnn.ipynb` — Kaggle notebook: dataset exploration, preprocessing, CNN training, evaluation and saving.
- `app.py` — Streamlit interface that loads the saved model and predicts an uploaded image.
- `class_names.json` — mapping from output index to vegetable class name; replace the placeholder with the file generated by Kaggle.
- `vegetable_cnn.keras` — trained model downloaded from Kaggle after training.
- `requirements.txt` — Python dependencies.

## Model and training
- CNN built from scratch; no pretrained model.
- Input size: 128 × 128 RGB.
- Training-only augmentation; validation/test only rescale pixel values.
- Multiclass categorical labels.
- Exactly 2 epochs.
- `EarlyStopping` and `ModelCheckpoint` callbacks.
- Test loss/accuracy and accuracy/loss plots are produced in the notebook.

## Run Streamlit locally
1. Download `vegetable_cnn.keras` and `class_names.json` from the Kaggle notebook output.
2. Put both files beside `app.py`. Replace the placeholder `class_names.json` with the actual mapping produced by the notebook.
3. Create and activate a virtual environment (optional but recommended).
4. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
5. Run:
   ```bash
   streamlit run app.py
   ```

The app performs inference only. It does not retrain the model.
